# PSI_projekt_zaliczeniowy

Projekt polega na analizie tekstu opinii pracowników o miejscu pracy (zawartych w pliku reviews.csv). Analiza wykorzystuje tworzenie korpusów tekstowych, czyszczenie i normalizację tekstu, tokenizację, stemming, usuwanie stopwords, analizę częstości występowania słów, analizę współwystępowania wyrażeń, tworzenie macierzy Term Document Matrix, modelowanie tematów oraz wizualizację danych tekstowych przy pomocy chmur słów.
